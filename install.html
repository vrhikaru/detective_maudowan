把偵探社裝到手機上

裝好之後就像一般 App，從桌面一點就能玩；玩過一次的案件，沒有網路也能玩。不想安裝的話，直接在瀏覽器裡玩也可以。

Android 手機、平板 試玩版

試玩版還沒有放上來，先用瀏覽器玩，或在 Chrome 選單裡按「安裝應用程式」／「加到主畫面」。

iPhone、iPad

  1. 用 Safari 打開這個網站（Chrome 或 LINE 裡的瀏覽器不行）。
  2. 點畫面下方（iPad 在右上方）的分享按鈕，就是方框加向上箭頭的那個圖示。
  3. 往下滑，點「加入主畫面」，再點右上角的「新增」。
  4. 回到桌面，點「毛豆丸」圖示就能開始玩。

直接在瀏覽器玩

手機、平板、電腦都可以。打開官網，在案件簿挑一個案件，按「開始辦案」。
